# 📸 SnapClass — AI Powered Attendance System

## 🌐 Live Demo
👉 [Click here to view live app](https://snapclass-ai-attendance-0505.streamlit.app/)

## 📌 Overview
SnapClass is an AI-powered smart attendance management system that automates student attendance using face recognition and voice recognition technology.
Teachers can upload a class photo, use live face recognition, or use voice detection to instantly mark attendance — 
no manual roll call needed!

## 🎯 Problem Statement
Traditional attendance marking is time-consuming and error-prone. SnapClass eliminates this by automating the entire process using AI, computer vision and voice 
recognition — making attendance instant, accurate and paperless.

## ✨ Key Features
- 📷 Upload class photo for automatic attendance
- 🤖 Real-time face recognition using OpenCV
- 🎙️ Voice recognition for attendance marking
- 📊 Attendance dashboard & records
- ⚡ Fast, accurate & easy to use
- 🌐 Fully deployed on Streamlit Cloud

## 🛠️ Tech Stack
- **Language:** Python
-  **Database:** Supabase
- **Computer Vision:** OpenCV-python-headless
- **Voice Recognition:** librosa, resemblyzer
- **Frontend/Deployment:** Streamlit
- **Libraries:** NumPy, Pandas, scikit-learn, segno, pillow

## 📊 Project Workflow
1. Student face & voice data registration
2. Class photo upload / live camera input
3. Face detection & recognition using OpenCV
4. Voice input detection & speaker matching
5. Automatic attendance marking
6. Attendance records & dashboard
